# Перенеси спеку на фронт

Копирует актуальную OpenAPI-спеку этого бэкенд-проекта во фронтенд-проект petHealth.

## Шаги

1. Прочитать `/Users/oka/Pet/open-api/spec.json` в этом проекте.
2. Сконвертировать его содержимое из JSON в YAML.
3. Записать результат в `/Users/oka/petHealth/openapi/reference/api.yaml`, полностью заменив содержимое файла (создать файл/директории, если их ещё нет).

## Ограничения

- Трогать **только** файл `/Users/oka/petHealth/openapi/reference/api.yaml`. Никакие другие файлы во фронтенд- или бэкенд-проекте не редактировать.
- Никакой генерации кода, клиентов, типов и т.п. — только сама спека в виде YAML.
- Не менять содержимое спеки по смыслу — только формат (JSON → YAML). Если возникают сомнения в конвертации — спросить пользователя, а не гадать.
