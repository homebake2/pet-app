# myauthservice

Go-бэкенд приложения для учёта здоровья питомцев. Команды разработки, архитектура и деплой — в [CLAUDE.md](CLAUDE.md) и [docs/deploy.md](docs/deploy.md).

## Тестовый аккаунт на проде

Для ручной проверки реального бэкенда (`https://pet-app-dk8u.onrender.com`) создан отдельный аккаунт через `POST /auth/register`:

| Поле | Значение |
| --- | --- |
| login | `smoke-test-bot` |
| password | `smoke-test-bot-2026` |

Аккаунт нужен только для smoke-проверок контракта (создать питомца и событие, прочитать список). Данных пользователей в нём нет; не использовать его для реальных данных. Питомец `Smoke` и событие в нём созданы при проверке мультипитомцев.
